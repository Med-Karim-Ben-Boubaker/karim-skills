# Icons

Tabler Icons (MIT, tabler.io/icons), stroked, `currentColor`. Copy the `<svg>` into a node, an icon node, or a group title as-is: the `ico` class sizes it, and the component sets its colour.

Pick an icon only when it tells the reader *what kind* of thing a box is faster than its label would. Use one icon per kind across a page, so "database" always looks the same. For a kind not listed, take its glyph from tabler.io/icons and keep the same attributes.
