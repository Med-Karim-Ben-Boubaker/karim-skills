# Credits

Adapted from the `no-comments` skill and its Comment Sicko reviewer in Lauren Tan's pstack (MIT License, Copyright (c) 2026 Lauren Tan): a fresh subagent that deletes comments against a short keep-list, flags the code each one propped up, and a parent that judges the report, fixes the flags and offers to encode claimed constraints. This version rewrites the wording, keeps docstrings on public functions and APIs, and reports in chat.
